# Cordless Stainless Steel Cat Water Fountain — Mock Landing Page Model

**Status:** Internal mock. Supplier validation underway. Nothing on this page is a verified product claim.
**Companion file:** `index.html` (the mock page itself, with a build-notes toggle and per-ad-angle hero preview).
**Funnel position:** Meta / TikTok ad → this landing page → **Shop** CTA → exact Shopify product page → Add to Cart → Checkout → Purchase.

The landing page's only job: **Attention → Interest → Desire → Trust → Click to Shopify.** The Shopify product page owns confirmation, cart, and checkout.

## 4. Mobile layout

Designed mobile-first at 390 px. Everything stacks in one column; the width rule is `min(100% − 40px, 1120px)`.

- **Nav:** logo left, Shop Now pill right. Section links hidden below 820 px (they are not needed on mobile; the sticky bar carries the CTA).
- **Hero:** eyebrow → H1 (34–62 px fluid) → sub → benefit line → two full-width-ish pill CTAs → hero image *below* the copy so the headline and CTA sit above the fold on a 390×844 screen. The image follows immediately, 4:5.
- **Problem:** headline and four short lines, then the two comparison tiles stacked with a ↓ between them.
- **Solution:** copy, then the product image, then the three benefit cards stacked.
- **Demo:** video placeholder first (16:10), then headline and the nine-step list in a single column, then CTA.
- **Features:** single column on narrow phones; two columns from 620 px.
- **Cordless:** dark band; copy and CTA first, then a 2×2 grid of room tiles.
- **Cleaning:** copy and four points, then a 2-column grid of six close-up tiles.
- **Compare:** table scrolls horizontally inside its own container (`overflow-x: auto`, min-width 520 px); the page body never scrolls sideways.
- **Included:** list first, then flat-lay and packaging placeholders.
- **Offer:** two plan cards stacked, Option B second with badge and solid CTA; both CTAs full width, 56 px tall.
- **Proof / FAQ / Final:** single column; FAQ uses native `<details>` with 18 px tap targets and a + / × indicator.
- **Sticky mobile CTA:** fixed bottom bar with product name and Shop Now (48 px tall), safe-area padding; hidden at ≥820 px. Body gets 84 px bottom padding so nothing is covered.
- Tap targets are ≥44 px everywhere; body type 17 px; paragraphs ≤62 ch.

## 8. Shopify handoff

**Where the page lives.** Two workable options:
1. Host `index.html` on a static host (Vercel, Netlify, Cloudflare Pages) under a subdomain such as `go.brand.com/fountain`. Fastest to iterate, cleanest pixel control, no theme constraints. Recommended for the paid-traffic test.
2. Rebuild as a Shopify page template (Online Store 2.0 sections) so it sits at `brand.com/pages/fountain`. Same domain as checkout, which some advertisers prefer. Slower to iterate.

**Linking to the exact product.** Each CTA links to the product page with the variant preselected:

```
https://STORE.myshopify.com/products/cordless-stainless-cat-fountain?variant=VARIANT_ID_A
https://STORE.myshopify.com/products/cordless-stainless-cat-fountain?variant=VARIANT_ID_B
```

Option B may instead be its own bundle product (`/products/complete-hydration-set`) if built with Shopify Bundles; either way the CTA targets the exact page the offer card describes. Never link to `/`, `/collections/all`, or a search.

**Optional direct add-to-cart.** For a later test, a cart permalink skips the product page: `/cart/VARIANT_ID:1?checkout[...]`. Not the default, because the product page is where confirmation and upsell happen and where Shopify's own ViewContent / AddToCart events fire.

**UTM passthrough.** The landing page must append the inbound `utm_*` and `angle` parameters to every Shopify link so ad → LP → Shopify attribution is continuous. Shopify keeps them through checkout.

**Message parity.** The Shopify product title, first image, price, and variant names must match the offer card the visitor clicked. Bundle contents on Shopify = Section 9 list.

**Pixels.** Meta Pixel and TikTok Pixel installed on both the landing page and Shopify (via the Meta / TikTok sales channel apps), same pixel IDs, so PageView → ViewContent → AddToCart → InitiateCheckout → Purchase is one journey.

## 9. Conversion rationale

| Section | Why it exists | Objection or question it resolves |
|---|---|---|
| Hero | Continues the ad's promise in the first second; gives the CTA before any scrolling | "What is this and what do I do?" |
| Problem | Recognition builds interest faster than features. Behaviour, not medicine | "Is this for me?" → "That's my cat." |
| Solution | Names the product once, gives three pillars, holds engineering back | "OK, so what is it exactly?" |
| Demonstration | Demonstrate rather than describe; a video sells routine better than copy | "Is it complicated? What's the daily reality?" |
| Feature grid | The "how" for people who need it, after the "why" | "Does it have X?" (capacity, filtration, quiet, cleaning) |
| Why cordless | The single argument only this product makes; the dark band makes it the page's visual thesis | "Why not the plug-in fountain I've seen?" |
| Cleaning | The biggest reason fountains get abandoned is cleaning. Answering it removes the strongest silent objection | "Will I actually keep this clean?" |
| Comparison | Frames the product against the customer's current state without naming competitors | "What do I gain over what I have?" |
| What's included | Concreteness reads as honesty; also pre-answers the bundle question | "What do I actually get?" |
| Offer | One clear choice, one preferred. Two options convert better than one because the customer decides *which*, not *whether* | "Which one?" |
| Social proof | Reserved so real proof drops in without a redesign; never faked | "Does anyone else use this?" (unanswered until true) |
| FAQ | Last-minute objections in the customer's own words, in provisional-safe language | Battery, noise, filters, app, size |
| Final CTA | Restates promise in three beats and asks once more | "Right, I'm in." |
| Sticky mobile bar | Mobile visitors scroll; the CTA travels with them | Removes the need to scroll back up |

## 11. Analytics plan

Events emitted by `index.html` to `dataLayer` (wire to GA4, Meta Pixel, TikTok Pixel at build):

| Step | Event | Where |
|---|---|---|
| Landing-page view | `lp_view` (with `angle`) | LP |
| Scroll depth | `lp_scroll_25 / 50 / 75 / 100` | LP |
| Main CTA click | `lp_cta_primary_click` (with `cta` ID) | LP |
| Secondary CTA click | `lp_cta_secondary_click` | LP |
| LP → Shopify click-through | derived | LP |
| Shopify product view | `ViewContent` | Shopify |
| Add to cart | `AddToCart` | Shopify |
| Initiate checkout | `InitiateCheckout` | Shopify |
| Purchase | `Purchase` | Shopify |

**Key metric — Landing Page → Shopify CTR:**

```
unique Shopify CTA clicks ÷ unique landing-page visitors
```

Report by `angle` and by `cta` ID so the hero variant and the CTA position can each be judged. No target numbers are set until the first traffic runs.
